                LOCAL DESCRIPTIVE REPORTING

                Projects / Field Summary

                Collect existing journal observations. This is a count of your selected records, not an AI summary, ecological inference, species verification, or evidence of trends.

                Site names are project labels only: the journal has no saved sites or coordinates. Membership is always chosen manually; new observations are never added automatically.

                Project details and included records

                One shared column, two separate values: site is your manual project label; species is the recorded name used for species-group matching. Both are kept in the saved scope and CSV.

                Every project needs a title. Day groups need a date and allow only that exact observation date. Species groups need a name and allow only that exact, case-sensitive name after trimming. Site groups need a site label. Site/custom groups allow any journal record. Changing scope deselects nonmatching records when saved.

                Include existing observations

                Projects stay in this browser. Completion locks editing until reopened; it is not a frozen snapshot. Deleting a journal record changes its summaries; missing references are shown, never counted. Journal JSON backups do not include projects. CSV is a readable report, not a project restore file.

                Identification provenance — staged definition

                No review status is assigned to any observation. These are three independent evidence tracks, not a ladder or automatic checkmarks. The current photo tool uses fixed mock suggestions, not AI identification.

                AI-suggested
                Future record: model/source and version, suggested taxon, date, evidence and uncertainty. A suggestion is not a confirmed identification.
                community-identified
                Future record: attributed reviewers, identification evidence, date and an explicit agreement/disagreement policy. No community consensus exists in this prototype.
                expert-confirmed
                Future record: named reviewer with relevant expertise, explicit confirmation, date and inspectable supporting evidence. Never awarded by AI scores, a lookup match, or a user merely selecting a label.

                Assignment is intentionally unavailable pending provenance/reviewer design. Journal records and version-1 JSON remain unchanged; no review metadata is saved or exported.

                Genetic Data

                Unconnected planning preview only. BOLD identification/search and GenBank record search are separate paths. No results, network calls, credentials, sequence submission or outbound data. GenBank submission would be a separate reviewed workflow, not a lookup.

                Up to 10,000 input characters. Plain IUPAC DNA or one FASTA record; no RNA, gaps or multiple records. Validation checks syntax, not quality, identity, or biological meaning. Never saved in journal, projects or exports. Clear when finished.
